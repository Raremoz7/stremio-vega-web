# stremio-vega-web

Build do [stremio-web](https://github.com/Stremio/stremio-web) (GPL-2.0) com:
- player nativo para Fire TV com Vega OS (VegaVideo, em um fork do stremio-video);
- login por QR Code;
- botao Voltar do controle remoto.

Carregado pelo app Fire TV do projeto stremio-vega. Uso pessoal.
